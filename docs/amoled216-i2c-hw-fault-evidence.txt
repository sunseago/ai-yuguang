AI余光 · Waveshare ESP32-S3-Touch-AMOLED-2.16 · I2C 硬件故障证据
============================================================

板卡：Waveshare ESP32-S3-Touch-AMOLED-2.16（SKU 33969）
现象：屏幕（CO5300 / QSPI）正常显示，但 I2C 总线（GPIO15=SDA, GPIO14=SCL）
      上所有器件——AXP2101(0x34)、CST9220 触摸(0x5A)、QMI8658(0x6B)、
      PCF85063 RTC(0x51)、ES8311 音频(0x18)——全部无应答。触摸与陀螺仪因此不可用。

实测定位（均带对照组）：
  1. 6 组引脚对 + 12kHz 位翻转扫描：0 器件，排除接错脚/上拉太弱
  2. 最小探针（不初始化屏幕、不加载库）：同样 0 器件，排除应用固件影响
  3. 推挽拉低 SDA，ADC 读 SCL = 204mV；反向 208mV；对照引脚无耦合
     => 两线间约 140Ω 低阻通路。若为未上电器件的 ESD 二极管钳位，
        读数应在 0.6~1.4V，实测 0.2V，故排除该可能
  4. 原理图：R21/R22 = 2.2k 上拉至 VCC3V3（与 140Ω 反推一致，VCC3V3 正常）
     触摸 I2C 经 J4 24pin 屏排线，pin19=TP_SDA、pin20=TP_SCL，为相邻脚
     板上无 I2C 专用 ESD 器件（仅 USB 有 TVS1），排除保护器件击穿
  5. 断电（拔电池）后依旧短接，不随时间/上电状态恢复

结论：SDA/SCL 之间存在约 140Ω 硬件搭连，三条官方固件在同一块板上全部卡在 I2C，
      与本仓库固件无关，属板卡硬件故障。
